# 🌟 自然發音樂園

基於**自然發音法**製作的互動式自然發音學習網站。

## 📚 課程來源
- 主要：自然發音法（共 20 章）
- 口訣補充：21天學會自然拼讀
- 規則補充：自然發音法規則全集—母音篇

## ✨ 功能特色
- 🔊 **點擊發音**（瀏覽器內建，不需 API）
- 🖼️ **單字配圖**（Unsplash 免費圖庫，需連網）
- ✏️ **每課小測驗** + 星星積分
- 📖 **每課繪本故事**（用學過的音組單字撰寫）
- 🇹🇼 **繁體中文規則說明** + 記憶口訣

## 🚀 上傳到 GitHub Pages

1. 在 GitHub 建立新 repository（例如 `phonics`）
2. 把所有 7 個檔案上傳到根目錄
3. Settings → Pages → Branch: main → Save
4. 約 1–2 分鐘後網站上線！

## 💡 使用提示
- 建議使用 Chrome 瀏覽器（語音功能最完整）
- 圖片需要網路連線（Unsplash）
- 進度儲存在裝置上，換裝置需重新學習
- 本網站與 ck-phonics 使用不同的進度儲存，互不影響
